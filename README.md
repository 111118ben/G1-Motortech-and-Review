## 🛠️ Cara Pakai

```bash
python3 build.py      # buat dashboard.html dari config.json
```

Lalu buka `dashboard.html` di browser. Selesai.

## ➕ Tambah Aplikasi

Tambahkan satu baris di `config.json`, jalankan ulang `build.py`.

```json
{"id": "baru", "name": "Aplikasi Baru", "desc": "Deskripsi", "icon": "🚀", "url": "https://contoh.com/"}
```
